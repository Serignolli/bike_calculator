# 🚴‍♂️ Calculadora do Pedal  

Uma aplicação interativa em **React + Tailwind** que calcula o impacto individual, ambiental e coletivo ao substituir o carro (ou outros modais) pela bicicleta.  
Com ela você descobre:  

- 💨 **CO₂ evitado** semanal e anualmente  
- 🔋 **Energia gerada** com dínamo ou rolo de treino  
- 🔥 **Calorias queimadas** e suas equivalências em alimentos  
- 💰 **Economia financeira** com combustível e estacionamento  
- 🌳 **Equivalente em árvores plantadas**  
- 🌎 **Poluentes evitados** (NOx, PM2.5 e CO)  
- 🔇 **Redução de ruído urbano**  
- 🏙️ **Espaço urbano liberado**  

Tudo isso com visual moderno, animações e comparações divertidas.  

---

## ✨ Funcionalidades  

- **Configuração do trajeto**: distância, dias por semana, velocidade média e modal substituído  
- **Energia**: simulação de geração com dínamo ou rolo de treino  
- **Financeiro**: cálculo de economia com combustível, estacionamento e tempo de deslocamento  
- **Impacto individual**: energia, calorias e tempo economizado  
- **Impacto ambiental**: emissões evitadas, qualidade do ar e poluição sonora  
- **Impacto coletivo**: espaço urbano e comparativos por passageiro  
- **Compartilhamento fácil** dos resultados com amigos  

---

## 🛠️ Tecnologias  

- **React** (com hooks e useMemo para cálculos)  
- **Tailwind CSS** para o design responsivo  
- **Lucide Icons** para ícones modernos  
- **TypeScript (parcial)** para maior clareza nos tipos  

---

## 🚀 Como rodar o projeto  

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/calculadora-do-pedal.git

# Acesse a pasta
cd calculadora-do-pedal

# Instale as dependências
npm install

# Rode o projeto
npm run dev
```
